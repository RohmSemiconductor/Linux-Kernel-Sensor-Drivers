# ROHM Ambient Light sensor IC BH1730

Driver for the BH1730 mbient light sensor has been submitted to upstream Linux
by Alexandre Hamamdjian. Driver is currently under review and some improvements
have been requested by the kernel community. You can find the driver and follow
and participate the reviewing process using the Linux IIO mail list.

Please, see the [lore.kernel.org](https://lore.kernel.org/all/?q=BH1730) for
up-to-date status.
