# ROHM {{ page.sensorname }} Analod to Digital Converter (ADC)

The ROHM {{ page.sensorname }} is a {{ page.bd7910xnumch }}-channel, 12-bit ADC which is controlled over SPI.

{% include resources.md %}

## Linux Driver:

{% include source_upstream_status_new.md %}

The driver supports reading the ADC channels via the Linux IIO subsystem. SPI MODE 3 (CPOL=1, CPHA=1) should be used.

{% include subsys_iio.md %}

### Devicetree example:

```
    spi {
        adc: adc@0 {
            compatible = "{{ page.compatible }}";
            reg = <0>;
            vdd-supply = <&dummyreg>; 
            iovdd-supply = <&dummyreg>;
            spi-cpha;
            spi-cpol;
{%- if page.spifreq %}
            spi-max-frequency = <{{ page.spifreq }}>;
{%- endif %}
        };
    }
```
